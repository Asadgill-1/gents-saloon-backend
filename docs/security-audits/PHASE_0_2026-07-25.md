## Evidence

- Platform dashboard: clean `npm ci`, lint, TypeScript, 3 tests, production build, and full `npm audit --audit-level=high` passed with zero vulnerabilities.

- Runtime smoke tests on both dashboards returned `307 /login` for unauthenticated `/`, `200` for `/login`, and the expected HSTS header.

- Development Redis and PostgreSQL bind only to `127.0.0.1`; Redis requires a password. `docker compose config --quiet` passed.
- Native PostgreSQL 17.10 binds to `127.0.0.1`/`::1`; the `gents_saloon` database is ready and reports `listen_addresses=localhost`.
